# ПЕРИМЕТР: ВЫНОС

Браузерный top-down экстракшен-экшен в духе Hotline Miami в аномальной Зоне отчуждения. Найдите невидимые артефакты по писку детектора, дотащите их до пролома в периметре и сдайте торговцу — или погибните и потеряйте всё несданное.

Версия 2.0 — медленное выживание с единой стилистикой: ограниченная палитра из 16 цветов, сумрак с тёплыми источниками света против холодного свечения аномалий, зерно и виньетка, детализированные спрайты с контурами.

Особенности:

- **Большие карты с туманом войны**: виден конус в направлении взгляда и небольшой радиус вокруг; звуки (шаги, рык, выстрелы) слышны раньше, чем виден источник. Миникарта показывает только разведанное.
- **Фракционная война**: стаи Хрипунов атакуют ближайшего человека, отряды Стервятников ходят маршрутами, прикрывают друг друга и отстреливаются — стравливайте их и зачищайте выживших.
- **4 типа аномалий** (жарка, воронка, разряд, кислота) — почти невидимы, у каждой свой звук; болт провоцирует и раскрывает их. Воронка затягивает.
- **Мета-прогрессия**: артефакты сдаются торговцу за валюту; покупается оружие, бронежилет, подсумок для болтов, расцветки. Смерть = потеря несданного хабара. Прогресс в localStorage.
- **Два слота оружия** (пистолет/обрез/автомат), подбор с трупов, ограниченный боезапас.
- **Выброс**: сирена, обратный отсчёт, добеги до здания или умри; после выброса аномалии смещаются.
- **Босс Горбач** на 5-й глубине: читаемые рывки, оглушается об стены и аномалии, гарантированный ценный артефакт.
- **Нейтральный сталкер у костра**: обмен артефакта на патроны и болты посреди рейда.
- **Модификаторы рейда**: ночь / стая / свежий выброс — показываются перед стартом.
- **Дневник**: автосгенерированная строка после каждой вылазки, листается у торговца.
- Процедурная расстановка на каждый заход, процедурный чиптюн-саундтрек, тряска экрана, гильзы и кровь до конца рейда.

Вся игра — один файл `index.html`: canvas 2D, чистый JS, без библиотек и сборки, звук через Web Audio.

## Запуск локально

Откройте `index.html` в браузере или поднимите статический сервер:

```
python3 -m http.server 8000
```

## Управление

**Десктоп:** WASD — движение, мышь — прицел, ЛКМ — выстрел/удар, Пробел — рывок, E/ПКМ — болт, Q/колесо/1-2 — смена оружия, F — обмен у сталкера, R — рестарт.

**Телефон:** стик слева; справа «БОЙ» (авто-прицел), «РЫВОК», «БОЛТ», иконка второго ствола — смена оружия; кнопка «ОБМЕН» появляется у костра сталкера.
