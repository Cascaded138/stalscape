# ПЕРИМЕТР: ВЫНОС

Браузерная 2D top-down экшен-игра в духе Hotline Miami, действие происходит в аномальной Зоне отчуждения. Одна вылазка — один заход: найдите невидимый артефакт по писку детектора, заберите его и уйдите через пролом в периметре — глубже в Зону. Смерть — с одного удара, рестарт — мгновенный.

Особенности:

- **Фракционная война**: мутанты-Хрипуны атакуют ближайшего человека — мародёров-Стервятников можно стравливать с ними и зачищать выживших.
- **4 типа аномалий** (жарка, воронка, разряд, кислота) — почти невидимы, у каждой свой звук; болт провоцирует и раскрывает их.
- **Процедурная расстановка**: враги, аномалии, укрытия, артефакт и выход генерируются заново при каждом заходе.
- **Сбор перед вылазкой**: цвет куртки, маска (противогаз/балаклава/капюшон), стартовое оружие из открытых, запас болтов.
- **Оружие с трупов**: пистолет, обрез, автомат — ограниченный боезапас, подбор заменяет текущее.
- **Процедурный чиптюн-саундтрек** и синтезированные звуки через Web Audio.

Вся игра — один файл `index.html`: canvas 2D, чистый JS, без библиотек и сборки.

## Запуск локально

Просто откройте `index.html` в браузере, либо поднимите статический сервер:

```
python3 -m http.server 8000
```

и откройте `http://localhost:8000`.

## Управление

**Десктоп:** WASD — движение, мышь — прицел, ЛКМ — выстрел/удар, Пробел — рывок, E или ПКМ — болт, R — рестарт вылазки.

**Телефон:** стик слева — движение, справа кнопки «БОЙ» (выстрел/удар, авто-прицел на ближайшего врага), «РЫВОК» и «БОЛТ».

## Деплой на GitHub Pages

В репозитории настроен workflow `.github/workflows/deploy-pages.yml`, который публикует содержимое репозитория на GitHub Pages при пуше в `main`.

Чтобы включить публикацию: **Settings → Pages → Source: GitHub Actions**. После первого прогона workflow игра будет доступна по адресу вида `https://<user>.github.io/<repo>/`.
