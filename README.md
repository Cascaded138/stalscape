# ПЕРИМЕТР: ВЫНОС

Браузерная 2D top-down экшен-игра в духе Hotline Miami, действие происходит в аномальной Зоне отчуждения. Одна вылазка — один заход: доберитесь до артефакта, заберите его и дойдите до точки эвакуации, избегая мародёров-Стервятников, мутантов-Хрипунов и аномалий-Марева. Смерть — с одного удара, рестарт — мгновенный.

Вся игра — один файл `index.html`: canvas 2D, чистый JS, без библиотек и сборки, звук через Web Audio API.

## Запуск локально

Просто откройте `index.html` в браузере, либо поднимите статический сервер:

```
python3 -m http.server 8000
```

и откройте `http://localhost:8000`.

## Управление

**Десктоп:** WASD — движение, мышь — прицел, ЛКМ — выстрел/удар, Пробел — рывок, R — рестарт вылазки.

**Телефон:** стик слева — движение, кнопка «БОЙ» справа — выстрел/удар (авто-прицел на ближайшего врага), кнопка «РЫВОК» — рывок.

## Деплой на GitHub Pages

В репозитории настроен workflow `.github/workflows/deploy-pages.yml`, который публикует содержимое репозитория на GitHub Pages при пуше в `main`.

Чтобы включить публикацию: **Settings → Pages → Source: GitHub Actions**. После первого прогона workflow игра будет доступна по адресу вида `https://<user>.github.io/<repo>/`.
